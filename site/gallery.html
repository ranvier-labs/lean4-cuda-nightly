mandelbrot

One cooperative block per SM. Warp workers claim 8×8 tiles from a shared ticket queue. 1024², 1000 iterations. The ownership map is which physical SM took each tile. 

@[cuda_kernel]
def mandelSM (output tileOwner coreTiles coreIters gcursor : Cuda.DevicePtr UInt32) :
    Cuda.DeviceM Unit := do
  let worker ← Cuda.SM.Worker.current warpsPerWorker
  let claims ← Cuda.dynamicShared (α := UInt32) 0
  let disp : Cuda.SM.Dispatch := { cursor := gcursor, claims, limit := numTiles }
  renderLoop disp worker output tileOwner coreTiles coreIters

plume_amr

Regridding-free quadtree. Every cell has a fixed slot, so refine/coarsen is flag-flipping in one cooperative megakernel. The shock stretch is the same tree with Godunov + HLLC. 

private def slotOf (level ix iy : UInt32) : UInt32 :=
  levelOffset level + iy * pow2 level + ix

@[cuda_kernel]
def plumeDynMega (u v s u2 v2 s2 p pn div hsq invhb srcFlag want frames diag :
    Cuda.DevicePtr Float32)
    (sLevel sIx sIy active factive : Cuda.DevicePtr UInt32)
    (count total frameEvery pIters : UInt32) : Cuda.DeviceM Unit :=
  plumeStep u v s u2 v2 s2 p pn div hsq invhb srcFlag want frames diag
    sLevel sIx sIy active factive count total frameEvery pIters 0

persistent_training

2048 SGD steps of a 16-class linear classifier inside one persistent launch. Forward, loss, both VJPs, Muon update — no host round-trip per step. 64-step mean loss 2.68 → 0.17. 

@[cuda_persistent]
def trainStep (item : TrainItem) (config : LinearClassifier.Config)
    (input : Cuda.DevicePtr Cuda.BFloat16) (labels : Cuda.DevicePtr UInt32)
    (logits logitGradient inputGradient : Cuda.DevicePtr Cuda.BFloat16)
    (losses weightMaster : Cuda.DevicePtr Float32)
    (weightModel weightGradient : Cuda.DevicePtr Cuda.BFloat16)
    (momentum secondMoment : Cuda.DevicePtr Float32) : Cuda.DeviceM Unit := do
  let shared : Cuda.DevicePtr UInt8 ← Cuda.dynamicShared (α := UInt8)
  LinearClassifier.runItem16 config {
    input
    labels
    logits
    logitGradient
    inputGradient
    losses
    weightMaster
    weightModel
    weightGradient
    momentum
    secondMoment
  } item.sample shared

stealth_shape_optimization

@[cuda_kernel]

    (workspace electric derivative widths widthGradient objectives
      scatteringObjectives residuals : Cuda.DeviceSlice Float32)
    (workerTouches smIds : Cuda.DeviceSlice UInt32) : Cuda.DeviceM Unit := do
  let candidate := (← Cuda.blockIdxX).toUSize
  let thread ← Cuda.Concurrent.Thread.blockIndex
  emptyMaterialFrom electricCandidate thread.rank thread.count edgeBins.size
