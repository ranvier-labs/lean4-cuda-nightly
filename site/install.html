Lean CUDA nightlies

Install a nightly

Nightlies are experimental Linux toolchains. Resolve the current release once, then pin its immutable ID in your project.

Requirements

  • Linux x86_64 or AArch64;
  • elan for the preferred installation path;
  • CUDA 13 nvcc for compiling CUDA programs;
  • a CUDA-13-compatible NVIDIA driver and supported GPU for execution.

Convenient elan installation

Read latest.json. If its release field is null, no public nightly exists yet. Otherwise follow its metadata URL and copy the exact installation.elanToolchain value. 

elan toolchain install ranvier-labs/lean4-cuda-nightly:nightly-YYYY-MM-DD
elan run ranvier-labs/lean4-cuda-nightly:nightly-YYYY-MM-DD lean --version
elan run ranvier-labs/lean4-cuda-nightly:nightly-YYYY-MM-DD lean --features

Require lean --features to contain CUDA. Put the same pinned value in a project's lean-toolchain; do not use a floating latest alias there. Current elan downloads the custom GitHub Release asset over HTTPS but does not compare it with this channel's checksum sidecar.

Checksum-verified installation

  1. Select the exact x86_64 or aarch64 artifact.
  2. Download its archive and checksum sidecar from the immutable release record.
  3. Run sha256sum -c <archive>.sha256.
  4. Extract with tar --zstd -xf <archive>.
  5. Set LEAN_SYSROOT to the extracted root and prepend its bin/ to PATH.
  6. Optionally register that root with elan toolchain link <name> <root>.
