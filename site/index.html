What a nightly means

Two native architectures

Linux x86_64 and Linux AArch64 are built from one immutable private source commit.

Validated after extraction

Each archive passes provenance, module-coverage, Lake CUDA smoke, and full-suite gates.

Private compiler source

Compiled toolchains omit private Lean sources. Required public CUDA SDK headers remain.

No implied performance claim

H100 validation is recorded separately and is not implied by an ordinary nightly.
